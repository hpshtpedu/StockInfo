# 愛心破牆小遊戲（love 帳號）— 現行設計

男生在最左邊等，女生從最右邊出發，一路用親親發出的愛心打破中間三面牆，最後兩人走到一起。放置型，不能操作，每天一定破關。

- 程式：`docs/love.js`（版本號在 `docs/index.html` 的 `GAMES.love`，例如 `love.js?v=8`）
- 素材：`docs/love/`，由 `python scripts/build_game_assets.py` 從 `mini_game/` 原檔縮製（跟戰鎚的 `docs/game/` 分開）
- 除錯：網址加 `?game=debug`（love 帳號登入時），出現時間滑桿（08:00～13:45）和漲跌幅輸入（產生假的 15 分 K）

---

## 1. 帳號

- `docs/private-verifier.json`：最上層是主帳號，`accounts` 裡是其他帳號。檔案裡只有 salt 和雜湊，沒有密碼。
- 新增或更換 love 帳號密碼：
  ```
  python scripts/make_private_verifier.py --profile love
  ```
  密碼至少 6 個字。跑完把 json commit 推上去；其他帳號的資料會原樣保留。
- 同一個登入頁，依密碼判斷是哪個帳號。

love 帳號登入後：

- 不用填股票張數，直接回首頁。
- 盤中市場的「我的自選股」整張隱藏。
- 小遊戲換成這個遊戲，只下載 `love.js` 和 `docs/love/`（約 137KB），完全不抓戰鎚檔案。
- 要登出：點原本進登入頁的入口 →「已登入」→ 登出。

## 2. 版面

```
+-----------------------------------------------------------+
| [男生]     [牆 0]      [牆 1]      [牆 2]          [女生] |  亞空間圖鋪滿
+-----------------------------------------------------------+
```

- 卡片高度＝戰鎚亞空間條的 1.5 倍：手機 61px，600px 寬以上 84px。
- 牆在卡片寬 30%、50%、70%，高度 84%，越左越厚。
- 女生停在牆右邊「牆半寬＋女生半寬＋14px」的地方。用像素算，手機上也不會貼著牆，像在親牆。

## 3. 一天的流程

| 時間 | 畫面 |
|---|---|
| 交易日 09:00 前 | 兩人站在兩端，牆完整 |
| 09:00 | 女生走到右邊那面牆前（1 分鐘，走路會上下晃） |
| 攻擊 | 女生換親親動作，朝牆發射愛心。打中時牆震一下、閃白，跳傷害數字 |
| 一面牆血量歸零 | 牆淡出縮小，女生走到下一面牆（1 分鐘） |
| 男生偶爾親親 | 男生換親親動作，頭上冒愛心（金光、慢慢飄）。女生發金光加持：射速 ×1.4、爆擊率 +15% |
| 三面牆都破了 | 兩人等速走向對方（2 分鐘），碰到後一起親親，中間一直冒愛心（1.5 倍大） |
| 收盤後到午夜 | 停在結局，一直親（卡片在畫面上才播動圖），顯示成功文字 |
| 休市日 | 兩人一起親親，寫「今天休息」（大字） |

結局文字：

- 靠自己破關：「大成功！費時 X 時 Y 分」，從 09:00 算到最後一面牆倒下，不到 1 小時就只寫分。
- 靠最後衝刺才破關：「成功！」。

傷害數字：普通 17px 粉紅字，爆擊 23px 金色大字加「!」。卡片矮，字不能太小。

## 4. 進度怎麼算（確定性，不是開著網頁才累積）

任何時間打開網頁，都從 09:00 一分鐘一分鐘重算到現在。手機、電腦看到的進度一樣，重新整理也不會重來。

- 盤勢：今天加權指數的 15 分 K，每根 K 棒從開到收線性內插到每一分鐘。報價每 2 分鐘更新一次。
- 隨機：用日期當種子。同一天、同一分鐘、同一用途永遠抽到同一個數，所以每台裝置結果一致，每天又都不一樣。

### 每分鐘的傷害

盤勢分數 mood（−1 很差 … +1 很好）：

```
mood = 0.6 × tanh(今天漲跌% ÷ 1.0) + 0.4 × tanh(這 15 分鐘漲跌% ÷ 0.25)
```

| 項目 | 公式 | 男生親親時 |
|---|---|---|
| 射速 | 每分鐘 18 顆 × (1 + 0.5 × mood) | × 1.4 |
| 每顆傷害 | 12 × (1 + 0.35 × mood) | — |
| 爆擊率 | 8% + 17% × max(0, mood)，爆擊傷害 ×2 | +15% |

每分鐘傷害：

```
每分鐘傷害 = 射速 × 每顆傷害 × (1 + 爆擊率) × 隨機 0.85～1.15
```

- 愛心大小跟著每顆傷害變；爆擊的愛心大 1.3 倍。
- 畫面上飛的愛心、跳的數字是依這組數字產生的視覺效果；真正的進度以上面的公式為準。

### 男生親親

- 每 15 分鐘抽一次，機率 `25% + 30% × max(0, 那段的 mood)`。
- 抽中就在那段裡的隨機時間親 3～5 分鐘。

### 牆的血量

```
總血量 = 60,000 × 每天隨機 0.85～1.15 × (1 + 連漲連跌加減)
```

- **連漲連跌加減**：看今天之前的交易日。
  - 連漲 N 天：+5% × N。連漲時盤勢好、打得快，牆厚一點才有挑戰。
  - 連跌 N 天：−5% × N。讓她輕鬆一點。
  - 最多 ±20%。
- **分給三面牆**：左 42%、中 33%、右 25%，各 ±3% 隨機，越左越厚。

大約的破關時間：

| 盤勢 | 破關時間 |
|---|---|
| 平盤日 | 12:15～12:40 |
| 漲 1.5% 的日子 | 11:20～11:40 |
| 大漲日（+2～3%） | 10:50 左右 |
| 跌 1.5% 以上的日子 | 靠最後衝刺 |

### 保證破關（最後衝刺）

- 13:00 起，每分鐘檢查：剩下的血量照目前速度趕不上 13:27，就把傷害提高到剛好 13:27 前打完。
- 走到下一面牆的時間會先扣掉。
- 最後一面牆最晚 13:27 倒下，兩人 13:29 前會合；收盤時一定是結局畫面。

## 5. 省電

- 射愛心、結局冒愛心、男生頭上的愛心：只在盤中（09:00–13:31）、網頁在前景、卡片在畫面上時才跑。
- 走路、攻擊的人物動圖：同樣條件，其餘時間換靜止圖。
- 結局親親：收盤後、休市日也播（卡片在畫面上、網頁在前景時），兩張小動圖耗電很低。
