# 股市大局觀

個人用的手機看盤儀表板：一頁看完台股盤中、國際市場、台股盤後的狀況。每個指標盡量附上**有歷史回測依據的判斷 badge**，而不只是列出數字。

- 網頁：GitHub Pages（`docs/`），深色主題，台股慣例紅漲綠跌，以 iPhone 寬度為主要設計目標
- 報價：Cloudflare Worker（`worker/`），網頁每 2 分鐘更新一次
- 每日資料：GitHub Actions 每晚排程（`scripts/`），結果存成 `docs/*.json`
- **純個人使用**：交易所資料受證交所《交易資訊使用管理辦法》規範，請勿公開散佈網址。網頁已設定 `noindex`，不讓搜尋引擎收錄。

## 架構

```
手機瀏覽器 ──每 2 分鐘──▶ Cloudflare Worker /quotes ──▶ Yahoo、證交所、期交所…
     │                    （Cache API 快取，看的人再多，上游也只被抓一次）
     └──▶ GitHub Pages：docs/index.html + docs/*.json（每晚排程產生的歷史資料）
```

| 部分 | 位置 | 部署方式 |
|---|---|---|
| 網頁 | `docs/index.html`（單一檔案，無建置步驟） | 推到 `main`，GitHub Pages 約 5–10 分鐘後更新。瀏覽器會快取約 10 分鐘，網址加 `?v=數字` 可強制取得新版 |
| 報價中繼 | `worker/src/index.js` | 推到 `main` 且改到 `worker/**` 時，自動部署（`.github/workflows/deploy-worker.yml`，需要 secrets `CLOUDFLARE_API_TOKEN`、`CLOUDFLARE_ACCOUNT_ID`） |
| 每日資料 | `scripts/*.py`（只用標準函式庫，`build_events.py` 另外需要 `holidays`） | `.github/workflows/daily-data.yml`：週一到週五台灣時間 21:30、23:00 各跑一次，改到 `scripts/**` 時也會觸發。同一時間只跑一個，排隊的那次會讀取最新的 `main` |

排程機器人會提交 `docs/*.json`，所以**推送前要先 `git pull --rebase`**。

### 私人自選股張數（今日增減 badge）

- 點標題「股市大**局**觀」的「局」進入 `private.html`（入口外觀跟一般文字一樣）。
- 先在自己電腦執行 `python scripts/make_private_verifier.py` 設定密碼（輸入時不顯示），把產生的 `docs/private-verifier.json` 推上去。檔案裡只有 PBKDF2 的 salt 與雜湊，**沒有密碼**；但雜湊公開，請用夠長、只用在這裡的密碼。
- 四檔張數用 Web Crypto（PBKDF2 + AES-GCM）加密存在**這個瀏覽器**，不上傳、不進 `/quotes`；換裝置要重新設定。
- 解鎖狀態只在同一分頁有效（重新整理不用再輸入）；「鎖定」或關閉分頁就要重新輸入。沒有閒置自動鎖定，共用裝置記得按鎖定。
- 首頁「我的自選股」旁顯示紅「▲x.x萬」／綠「▼x.x萬」＝最後一個交易日的 Σ（現價−昨收）×張數×1000。開盤後一直顯示（半夜、週末、連假也看得到），到下一個交易日 08:15 才隱藏、等開盤再出現；任一檔缺報價時不顯示。不含當日交易、股利、稅費。

## badge 原則

- **badge 寫數字代表的意義**（例如「護盤」），數字本身放在卡片內容裡。
- **實心底色** = 少見、達門檻才出現的事件；**文字顏色** = 幾乎一直顯示的狀態；**灰色** = 中性說明。
- **門檻要有回測依據**，目標是大約只在 10–15% 的日子亮起。用長期資料驗證後沒有支持的「體感」badge 一律拿掉。

## 回測結論：擇時 vs 定期定額

曾經有一張「正二風向球」卡片，依 VIX、散戶多空比、費半月線、加權季線決定這 10 天要不要加碼正二（00685L）。它能分出「好時機」與「普通時機」（之後 20 日平均 +2.9% vs +0.3%），但**用總資產回測後已拿掉**：

| 買法（每月預算相同） | 00685L 實際 2018–2026 | 模擬正二 2008–2026 |
|---|---|---|
| 每月第一個交易日買固定金額 | 基準 | 基準 |
| 每 10 天買一次，燈號「按兵不動」就跳過 | 平均成本 +8.3%，總資產少約 20% | 平均成本 +1.6%，總資產少約 17% |
| 月初看燈號，按兵不動就隔天再看 | 幾乎一樣（+0.1%） | 幾乎一樣（−1.0%） |
| 每月留一份，等 VIX 破 40 分 4 批買 | 平均成本 +3.6% | 平均成本 −1.4% |
| 每年第一個交易日一次買整年 | 平均成本 −8.8% | 平均成本 −5.3%（但 2008 年 +63%、2022 年 +41%） |

- **原因**：長期向上的市場，等待本身有成本（正二每天平均約 +0.08%）。「按兵不動」之後的 20 天平均仍是正的，所以跳過一定吃虧。只用過去資料決定何時買的規則，若無法預測「會跌」，平均只會買得更貴（下鞅的 optional stopping）。
- 早期「每 10 天買一次 +1.94% vs +1.53%」的結論只比較有買的那幾筆、沒算跳過的錢，是錯的。
- **風險面**：持續入金會讓「帳戶金額回撤」看起來比較小，要看排除入金的淨值回撤。模擬正二 2008–2026 全額投入的淨值回撤是 −82%。留一部分現金的買法回撤比較小，但這是**持有現金的效果**：「第 4 張等 VIX 破 40」和「第 4 張每年一月固定分批投入」的結果幾乎一樣（實際 10.93 vs 11.01 倍；模擬 15.32 vs 15.30 倍），VIX 訊號本身看不出額外價值。股利假設會讓「全買」和「留銀彈」的排名互換，兩者差距在誤差範圍內。
- **模擬模型校準**：實際 00685L 2018–2025 年每年平均比「加權價格日報酬 × 2」多約 7.4%（2018–2022 年 8–14%，2023–2025 年 −1–4%）。最可能的原因是台指期逆價差的轉倉收益（含股利）。原本模擬「扣 1.2%/年」嚴重低估。把殘差從 −1.2% 試到 +12%/年，各買法的排名都不變：年初一次買 > 每年固定投入 ≈ 月初看燈號 ≈ 每月全買 ≳ VIX 銀彈 ≫ 按兵不動跳過（−15% 到 −16%）。零成交日（2022 年有 28 天）改成不能成交，結果幾乎不變。
- 暴跌後等反彈的回測，訊號一律等到隔天才執行，避免用收盤才知道的訊號在同一個收盤價買進；結果依然平均打平、中位數小輸。
- **仍然成立的**：VIX 高預測之後**會漲**（第一次收盤破 40 後，60 日全數上漲），但「存現金等 VIX 破 40 再投入」並沒有比固定日期投入好，所以台指VIX 卡片只標「極度恐慌」，不寫成買進訊號。
- **正二的風險**：模擬正二 2008 年最大跌幅 −85%，等了 13 年才回到前高；盤整期會磨損（2011–2016 年加權 +3%、模擬正二 −15%）。磨損是持有期間依波動累積的，挑進場時機避不開。

### 其他回測過的結論

- **台指VIX**：第一次收盤破 40（2016 年起 7 次），隔天買進後 20 日有 6 次上漲，60 日全部上漲，但 20 日內仍可能再跌 5–8%。2008 年 VIX 破 40 後台股又跌了約兩個月，要分批。
- **台指VIX 的「5 日升溫 / 降溫」**：同一 VIX 水位下，5 日變化對之後 10 / 20 日沒有可靠的差別，已從卡片拿掉。
- 乖離過熱後通常**繼續漲**，乖離超跌後也**不特別好**；融資維持率、外資淨 OI 變化都沒有可靠的預測力。
- 限制：回測期間以多頭為主；散戶多空比只有 2020 年後的資料；2016 年前的 VIX 用美國 VIX 代替。

## 維護備忘

- **改網頁前先在本機實際跑過**：這台電腦沒有 Node。做法是把 Worker 的 `/quotes` 存成檔案，複製 `docs/*.json`，把 `index.html` 裡的 API 網址換成本機檔案，用 `python -m http.server` 開起來，再用 Edge 無頭模式 `--dump-dom` 確認狀態列顯示「更新 HH:MM」，不是「更新失敗」。
- **長期回測資料**：`mm_data/` 是從 MacroMicro 圖表手動匯出的長期資料（VIX、外資 OI、散戶多空比、融資維持率），只供本機分析，已加入 `.gitignore`，**不要提交**。匯出方法：在瀏覽器 console 執行
  ```js
  copy(Highcharts.charts.find(c => c && c.series).series.map(s => ({ name: s.name, data: s.options.data })))
  ```
  執行前先把圖表範圍調到最長，Highcharts 通常只載入目前顯示範圍的資料。
